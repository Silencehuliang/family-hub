## 1. 全局交互约定

### 1.1 导航结构

**移动端（底部 5 Tab）**：
```
工作台 | 账单 | ➕(记账FAB) | 日程 | 我的
```
> 记账 FAB 居中凸起，全局可见（除登录/绑定页），主入口。

**PC 端（左侧导航）**：
```
工作台 / 账单 / 日程 / 待办 / 购物清单 / 我的
```

### 1.2 通用操作模式
| 操作 | 方式 |
|------|------|
| 返回 | 顶部左上角 ←（移动）；浏览器后退（PC） |
| 新增 | 右下角 FAB 或右上角 + |
| 编辑 | 列表项点击进详情 → 顶部编辑 |
| 删除 | 列表项左滑（移动）/ 右侧 ⋯ 菜单（PC） |
| 筛选 | 顶部下拉 / 筛选图标弹层 |
| 切换月份 | 顶部左右箭头 + 月份点击 |
| 提交反馈 | Toast（成功 1.5s 自动消失） |
| 二次确认 | 删除等危险操作弹确认框 |

### 1.3 离线交互
- 检测离线：顶部黄色横幅 "当前离线，操作将在联网后同步"
- 离线下可查看缓存数据、可新增（进队列，标记"待同步"角标）
- 联网后自动同步，成功 Toast "已同步"

### 2.2 欢迎页
- Logo + 应用名 + slogan「让家庭事务井井有条」
- 主按钮「加入家庭」（输入邀请码）
- 次按钮「创建家庭」（首个成员即管理员）

### 2.3 输入邀请码
```
┌─────────────────────────┐
│  ← 加入家庭              │
├─────────────────────────┤
│                         │
│  请输入 6 位邀请码       │
│  ┌─┐┌─┐┌─┐┌─┐┌─┐┌─┐    │
│  │ │ │ │ │ │ │ │       │  6 格输入，自动跳格
│  └─┘└─┘└─┘└─┘└─┘└─┘    │
│                         │
│  你的昵称                │

│                         │

```
- 校验：邀请码有效期、剩余次数
- 失败：红色提示「邀请码无效或已过期」

### 2.4 设置 PIN
```
┌─────────────────────────┐
│  设置支付/登录 PIN       │
├─────────────────────────┤
│                         │
│      请输入 4 位 PIN     │
│       ●  ●  ○  ○        │  数字键盘
│                         │
│      [ 0~9 数字键盘 ]    │
│                         │
│  再次输入以确认          │
│       ○  ○  ○  ○        │
│                         │

```
- 两次一致 → 绑定设备 → 进工作台
- 不一致 → 清空重输 + 提示

### 2.5 设备绑定成功提示
- 弹窗「✅ 设备已绑定，以后本设备只需输入 PIN 即可登录」
- 自动进工作台

## 3. 日常登录流程

```
打开应用（未登录会话）
   │
   ▼
[PIN 输入页]
   ├── 设备已信任 + PIN 正确 ──▶ 工作台
   ├── PIN 错误 ──▶ 抖动 + 计数（剩余 X 次）
   ├── 5 次错误 ──▶ 锁定 30 分钟
   └── 设备未信任 ──▶ 提示"请联系管理员重新邀请"
```

**PIN 输入页交互**：
- 自动聚焦数字键盘
- 输完 4 位自动校验，无需点确认
- 剩余次数提示："PIN 错误，还可尝试 3 次"
- 锁定后倒计时显示

## 5. 账单模块交互

### 5.1 快速记账（核心流程，3 步）

**触发**：FAB / 工作台卡片 / 账单页 +

```
步骤 1：金额 + 分类
┌─────────────────────────────────┐
│  ← 记账                    保存 │
├─────────────────────────────────┤
│                                 │
│         ¥ 0.00                  │  大金额显示
│       [数字键盘]                │
│                                 │
├─────────────────────────────────┤
│  选择分类                       │
│  🍚餐饮 🛒日用 💡水电 👕服饰      │  宫格 4列
│  🏥医疗 🚗出行 📚教育 🎮娱乐      │
│  💻数码 🏠住房 🍼育儿 🎁人情      │
│  💼金融 ✈️其他                   │
├─────────────────────────────────┤
│  付款人：小明 ▼   日期：今天 ▼   │
└─────────────────────────────────┘
```
- 输金额 → 点分类 → 自动可保存
- 点分类弹出二级分类选择：
```
  🍚 餐饮
  ┌────────────────────┐
  │ 三餐   外卖   零食饮│
  │ 料    料    料     │
  │ 聚餐   果蔬生鲜  + │
  └────────────────────┘
```
- 选完二级即填入，可继续补充

**步骤 2（可选）：补充**
- 顶部「展开更多」：标签、备注、小票、周期
- 标签：多选 + 新建
- 小票：拍照 / 相册

**步骤 3：保存**
- 点「保存」→ Toast「已记录」→ 返回
- 离线时 Toast「已暂存，联网同步」

## 11. 状态机（关键流转）

### 11.1 待办状态
```
待办 ──(指派/开始)──▶ 进行中 ──(完成)──▶ 已完成
  ▲                                          │
  └──────────(撤回完成)─────────────────────┘
```

### 11.2 购物清单状态
```
待开始 ──(开始采购)──▶ 进行中 ──(全部已买/手动结束)──▶ 已完成
```

### 11.3 设备状态
```
未信任 ──(邀请码+PIN)──▶ 已信任 ──(吊销)──▶ 已吊销
                                       (重新邀请)──▶ 未信任
```

### 11.4 账单导入任务
```
上传中 ──▶ 解析中 ──▶ 校验中 ──▶ 待确认 ──▶ 导入中 ──▶ 完成/失败
```

## 12. 边界与异常处理

| 场景 | 处理 |
|------|------|
| 无网络时记账 | 进离线队列，标"待同步"，联网重试 |
| 邀请码失效 | 提示 + 引导联系管理员 |
| PIN 锁定 | 倒计时 + 管理员可远程解锁 |
| 飞书 webhook 失败 | 自动重试 3 次，失败入告警日志，Web Push 兜底 |
| 导入文件格式错 | 友好提示 + 模板下载 |
| 删除账单 | 二次确认 + 30 天内可在"回收站"恢复 |
| 重复导入 | 按金额+日期+分类指纹去重提示 |
