# 家庭管家 · UI 设计规范

> 版本：v1.0 ｜ 日期：2026-06-15
> 关联：PRD.md、架构设计.md、交互设计.md
> 定位：移动优先的 PWA，视觉温暖、操作高效、信息清晰。

---

## 1. 设计原则

| 原则 | 说明 |
|------|------|
| 温暖亲和 | 家庭场景，避免冷冰冰的企业感，配色偏暖 |
| 高效记账 | 核心动作 3 步内完成，常用入口常驻 |
| 信息层级清晰 | 重要数据大字号突出，次要信息弱化 |
| 一致性 | 颜色、间距、组件全站统一 |
| 移动优先 | 单手可操作，关键按钮在拇指热区 |

## 2. 色彩系统

### 2.1 主色（品牌色）
- **主色**：`#FF8C42`（暖橙）— 用于主按钮、Tab 高亮、强调
- **主色浅**：`#FFF1E6`（背景色块）
- **主色深**：`#E6701F`（按下态）

> 选暖橙：家庭温馨感，且与"支出"语义弱关联（红色太紧张，绿色像收入，橙色平衡）。

### 2.2 语义色

| 语义 | 颜色 | 用途 |
|------|------|------|
| 收入/正向 | `#52C41A` 绿 | （V1 暂不用，预留） |
| 支出/警示 | `#FF4D4F` 红 | 超支、错误、删除 |
| 提醒 | `#FAAD14` 橙黄 | 待办、日程临近 |
| 信息 | `#1890FF` 蓝 | 链接、提示 |
| 成功 | `#52C41A` 绿 | 完成提示 |

### 2.3 中性色

| 用途 | 浅色主题 | 深色主题 |

## 3. 字体规范

### 3.1 字体族
```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Microsoft YaHei", "Helvetica Neue", Helvetica, Arial, sans-serif;
```

### 3.2 字号阶梯（移动端基准）

| Token | 字号 | 行高 | 用途 |
|-------|------|------|------|
| `display` | 28px | 36px | 首页大数字（本月支出） |
| `h1` | 20px | 28px | 页面标题 |
| `h2` | 18px | 26px | 卡片标题 |
| `h3` | 16px | 24px | 小标题、列表主文本 |
| `body` | 14px | 22px | 正文 |
| `caption` | 12px | 18px | 辅助、时间戳 |

### 3.3 字重
- 常规：`400`
- 中等：`500`（标题、金额）
- 粗体：`700`（首页关键数字）

## 4. 间距与栅格

### 4.1 间距 Token（4 的倍数）

| Token | 值 | 用途 |
|-------|----|----|
| `xs` | 4px | 紧凑间隔 |
| `sm` | 8px | 元素内 |
| `md` | 12px | 列表行间距 |
| `lg` | 16px | 卡片内边距 |
| `xl` | 24px | 卡片间距、区块间距 |
| `xxl` | 32px | 大区块分隔 |

### 4.2 容器宽度
- 移动：左右各 `16px` 安全边距，内容最大 `100%`
- PC：居中最大 `480px`（手机风格）/ `1200px`（桌面看板）可切换

### 4.3 圆角
| Token | 值 | 用途 |
|-------|----|----|
| `sm` | 6px | 标签、小按钮 |
| `md` | 10px | 卡片、输入框 |
| `lg` | 16px | 大卡片、底部弹层 |
| `full` | 999px | 头像、悬浮按钮 |

## 5. 阴影与层级

| 层级 | 阴影 | 用途 |
|------|------|------|
| 卡片 | `0 1px 2px rgba(0,0,0,0.04)` | 默认卡片 |
| 浮层 | `0 4px 12px rgba(0,0,0,0.08)` | 弹窗、下拉 |
| 悬浮按钮 | `0 6px 16px rgba(255,140,66,0.35)` | 主 FAB（主色阴影） |

## 7. 基础组件规范

### 7.1 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| 主按钮 | 主色背景 + 白字 + 圆角 10 | 记账、保存 |
| 次按钮 | 白底 + 主色字 + 主色边框 | 取消、次要操作 |
| 文字按钮 | 无背景 + 主色字 | 链接、更多 |
| 危险按钮 | 红色背景 + 白字 | 删除 |
| FAB | 主色圆形悬浮 + 加号 | 首页快捷记账 |

- 高度：大 44px / 默认 40px / 小 32px
- 点击态：透明度 0.7 或加深一档

### 7.2 卡片
- 白底（深色：`#1F1F1F`）
- 圆角 10px
- 内边距 16px
- 阴影见第 5 节
- 卡片间距 12px

### 7.3 列表行
- 高度 ≥ 56px（保证触控）
- 左图标 + 主文本（h3）+ 次文本（caption 灰）+ 右操作 / 箭头
- 分组带 sticky 标题

### 7.4 输入框
- 高度 44px
- 圆角 10px
- 占位符：次文字色
- 聚焦：主色边框 1.5px
- 错误：红色边框 + 下方红色提示

### 7.5 标签（Tag）
- 圆角 6px、高度 24px
- 用户标签：自定义颜色浅底 + 深字
- 状态标签：语义色

### 7.6 底部 Tab（移动端）
- 4~5 个：工作台 / 账单 / 日程 / 待办 / 我的
- 选中：主色 + 实心图标；未选中：灰色 + 线性图标
- 高度 56px + 底部安全区

### 7.7 侧边导航（PC）
- 左侧固定 200px
- 同样 4~5 项，选中主色背景块

## 9. 深色模式

- 通过 `prefers-color-scheme` 自动 + 手动切换
- CSS 变量统一管理（`--bg-card`、`--text-main` 等）
- 图表配色同步调暗
- 分类图标圆形背景透明度调低（10%）

---

## 10. 动效

| 场景 | 动效 |
|------|------|
| 页面切换 | 左右滑入 200ms |
| 弹窗 | 上滑 + 遮罩淡入 250ms |
| 按钮点击 | 缩放 0.98 + 透明度 |
| 列表项删除 | 左滑显示删除 + 收起 |
| 数据加载 | 骨架屏（卡片灰块闪烁） |
| 数字变化 | CountUp 动画（首页支出） |

---

## 11. 图表风格

- 基于 ECharts 自定义主题
- 配色用第 2.4 分类色板
- 网格线浅灰 `#F0F0F0`
- 柱状 / 折线圆角、去边框、去多余图例
- 移动端图表高度 200~240px，支持点击下钻

---

## 12. 无障碍

- 颜色对比度 ≥ 4.5:1（WCAG AA）
- 所有可点击元素 ≥ 44×44px
- 图标配 `aria-label`
- 支持系统字体放大
- 关键流程键盘可达（PC）

---

## 13. 空状态与错误状态

| 状态 | 设计 |
|------|------|
| 空列表 | 插画 + 一句引导文案 + 主按钮（如"记一笔"） |
| 加载失败 | 插画 + 错误说明 + 重试按钮 |
| 无网络 | 顶部横幅提示"离线模式，部分功能不可用" |
| 权限不足 | 友好提示 + 返回 |
